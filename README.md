# Rajasthan — Animated Travel Website

A responsive, cinematic Rajasthan travel landing page made with plain HTML, CSS, and JavaScript. Built to be easy to edit on an Android phone.

## Files
- `index.html` — page structure and content
- `styles.css` — visual design, responsive layout, and animations
- `script.js` — mobile menu, scroll reveals, destination filters/search, theme toggle, and trip planner
- `assets/design-reference.png` — generated visual reference (if included)

## Run it on Android
1. Extract `rajasthan_animated_website.zip`.
2. Open `index.html` in a browser, or use an editor/preview app such as Acode.
3. Internet is needed for the remote destination photos and Google Fonts.
4. To publish it, upload the files to GitHub Pages, Netlify, or another static hosting service.

## Customise
- Change hero and destination photo URLs in `index.html` / `styles.css`.
- Change colors at the top of `styles.css` under `:root`.
- Add destinations by copying one `.destination-card` in `index.html` and setting its `data-tags` and `data-name`.
- This is a front-end demo: the trip planner does not book travel or send data to a server.

## Notes
The site uses external Unsplash image URLs and Google Fonts. Replace them with licensed/local assets before a commercial launch. Test the photos on your device and replace any URL that does not load.
